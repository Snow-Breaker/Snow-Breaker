# Profile artwork

Hero: generated with the built-in image_gen tool from the original BariPluxClassicLogo.png and BariPluxLogo.png references supplied by the owner.

Prompt: A premium ultrawide 3:1 GitHub cover for BariPlux. Black obsidian, translucent blue ice shards, liquid chrome, cobalt lighting. Large white BariPlux typography, SNOW-BREAKER, BUILDING THE NEXT CHAPTER. Right-hand silver BPT emblem based on the supplied original. Bottom caption: WINDOWS TOOLS / ANDROID AHEAD / BEYOND BPT. Preserve recognizable brand identity; no fake UI or extra third-party marks.

The project cards and social buttons are rendered from code by build-profile.cjs, using sharp. Original logos are in assets/brand. Social brand paths come from Simple Icons v16 (https://github.com/simple-icons/simple-icons), CC0; trademarks remain with their owners.

Rebuild panels from the repository root with `node tools/build-profile.cjs` (requires sharp). Hero is a separate generated artwork. It is not rebuilt by that command.
